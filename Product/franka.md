## 1. Franka Research 3 Dual-Arm Robot

### Overview / 产品概述

The system fuses vision with force sensing and adjusts both arms in real time, allocating grasping and transport tasks precisely to avoid conflicts, speed up execution and maintain high precision. Dynamic torque distribution and coordination algorithms let several tasks run in parallel and hand over seamlessly. It suits university research and medical applications.

系统融合视觉感知与力觉传感，实时协调调整双臂动作，将抓取与搬运任务精确分配，避免双臂运动冲突，在提升执行效率的同时保持高精度。动态力矩分配与协同算法使多项任务可并行执行、无缝交接。适用于高校科研与医疗应用场景。

### Key Features / 核心特点

- **Vision–force fusion 视觉+力觉融合** — Real-time adjustment of both arms based on fused perception feedback
- **Task allocation 任务智能分配** — Grasping and transport tasks assigned precisely to avoid conflicts
- **Parallel execution 多任务并行** — Dynamic torque distribution lets several tasks run in parallel with seamless handover
- **High precision 高精度** — Precision maintained throughout coordinated operation

### Typical Applications / 典型应用

| Application 应用 | Description 说明 |
|------------------|------------------|
| University research 高校科研 | Platform for dual-arm coordination, AI manipulation research 双臂协同与 AI 操作研究平台 |
| Medical applications 医疗应用 | Precise, force-aware assistance for clinical scenarios 面向临床场景的精准力觉辅助 |

### Specifications / 主要参数

| Item 项目 | Parameter 参数 |
|-----------|----------------|
| Degrees of Freedom 自由度 | 2 × 7-DoF（双臂） |
| Force Control 力控 | Joint torque sensing per arm 全关节力矩传感 |

## 2. Mobile FR3 Duo

### Overview / 产品概述

Mobile FR3 Duo is a mobile dual-arm platform built around two Franka Research 3 force-controlled arms. Drawing on the FR3's native high-precision force control, it supports coordinated dual-arm operation and can be repositioned with ease. An open FCI interface makes it compatible with ROS, MATLAB and other development environments — ideal for frontier robotics research such as human–robot interaction, dual-arm assembly and collaborative manipulation.

Mobile FR3 Duo 是基于两台 Franka Research 3 力控机械臂构建的移动双臂平台。依托 FR3 原生的高精度力控能力，平台支持双臂协同作业，且整机可灵活移动换位。开放的 FCI 接口使其兼容 ROS、MATLAB 等开发环境，是人机交互、双臂装配、协作操作等前沿机器人研究的理想平台。

### Key Features / 核心特点

- **Dual force-controlled arms 双力控机械臂** — Two FR3 arms with native high-precision force control 原生高精度力控
- **Mobile platform 移动底盘** — Easily repositioned between workstations 可在工位间灵活移动部署
- **Open development 开放开发** — FCI interface compatible with ROS, MATLAB and more 兼容主流开发环境
- **Coordinated operation 双臂协同** — Purpose-built for collaborative manipulation tasks 面向协作操作任务设计

### Typical Applications / 典型应用

| Application 应用 | Description 说明 |
|------------------|------------------|
| Human–robot interaction 人机交互 | Frontier HRI research 前沿人机交互研究 |
| Dual-arm assembly 双臂装配 | Coordinated precision assembly tasks 协同精密装配任务 |
| Collaborative manipulation 协作操作 | Research on multi-arm collaborative manipulation 多臂协作操作研究 |

### Specifications / 主要参数

## 3. Diana 7 Robotic Arm

### Overview / 产品概述

Diana 7 is a 7-DoF collaborative arm. Its seven-axis layout gives smoother motion and lets it steer around obstacles in tight, complex workspaces, while balancing payload and precision to handle parts of different sizes — picking, placing and transferring — making it a good fit for research experiments and fine manipulation.

Diana 7 是一款七自由度协作机械臂。七轴结构设计带来更平滑的运动轨迹，使其能够在狭窄复杂的工作空间中灵活避障；同时在负载与精度之间取得良好平衡，可胜任不同尺寸零件的拾取、放置与搬运作业，是科研实验与精细操作的理想选择。

### Key Features / 核心特点

- **7-DoF configuration 七轴构型** — Smoother motion with redundancy for obstacle avoidance 冗余自由度实现灵活避障
- **Compact workspace adaptability 狭窄空间适应** — Operates reliably in tight, complex workspaces 狭窄复杂空间稳定作业
- **Payload–precision balance 负载精度兼顾** — Handles parts of various sizes 处理多尺寸零件
- **Fine manipulation 精细操作** — Ideal for research experiments and precision tasks 科研与精密作业理想选择

### Typical Applications / 典型应用

| Application 应用 | Description 说明 |
|------------------|------------------|
| Research experiments 科研实验 | Force-controlled manipulation research 力控操作研究 |
| Fine manipulation 精细操作 | Picking, placing and transferring of various parts 不同零件的拾取、放置与搬运 |

### Specifications / 主要参数

| Item 项目 | Parameter 参数 |
|-----------|----------------|
| Degrees of Freedom 自由度 | 7-DoF |
| Type 类型 | Collaborative robotic arm 协作机械臂 |
| Force Control 力控 | Torque sensing in every joint 全关节力矩传感 |
